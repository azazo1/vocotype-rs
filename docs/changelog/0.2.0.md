# VocoType v0.2.0

VocoType v0.2.0 改进 macOS 录音体验, 支持在聆听期间降低其他应用音量, 并完善 tag 发布流程.

## Highlights

- feat(audio): macOS 14+ 可通过 AVAudioEngine Voice Processing IO 在录音期间降低其他应用音量, 停止采集后自动恢复.
- feat(settings): 可从状态栏菜单, TOML 配置, `--duck-other-audio` 参数或 `VOCOTYPE_DUCK_OTHER_AUDIO` 环境变量控制该功能.
- fix(audio): Voice Processing IO 启动失败时自动回退到 CPAL, 继续提供普通录音.

## Release

- fix(release): 发布任务会重新获取 annotated tag 对象, 避免检出流程覆盖本地 tag 引用后丢失说明正文.
- ci(release): GitHub Actions 支持手动选择已有 tag, 并统一使用该 tag 进行检出, 版本校验, 构建和发布.

## Upgrade Notes

- macOS app 最低系统版本由 macOS 13 提升到 macOS 14.
- 音频 ducking 默认关闭, 现有配置无需迁移.
